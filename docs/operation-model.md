## 二、核心：①②③ 決策管線（每條訊息都走）

**① 決策模型選內容**（Jev，一次 6 題）
- 讀：persona、最近 8 則群對話、最新一條訊息、群共享備註、成員備註、台北時間提示
- 選：**回什麼**（回話 / reaction / 貼圖 / 等待觀察）、**接哪句話的話題**（候選由 SDF 動態提供＝群裡最近 3 則非自己訊息＋「自然接話」）、**用什麼方式**（回答 / 安慰 / **色情挑逗誘惑勾引** / 追問 / 等待）、**表達哪些內容要點**（接對方重點 / 表達自己狀態 / 把問題丟回去 / 延伸到日常）、**長度**（一句 ≤14 字 / 兩則 ≤40 字）、**露骨檔位 0–3**
  - 0 純日常不撩｜1 若即若離｜2 明顯勾引露骨主動｜3 尺度完全放開無底線
  - 回應方式選 **等待** → 這一輪不開口（合法的決策結果，不是失敗）；被 @、被回覆、要圖要語音時仍然必回
- 被 @、被回覆、對方在要圖/語音 → 強制文字回覆（決策仍提供露骨檔位做參考）
- ① 超時或失敗 → 走舊路徑（45% reaction 閘＋正常文字流）

**② 文字模型生成**
- qwen 收到：原始上下文（最近 10 則＋被回訊息＋備註＋時間提示）＋「前置決策指示」整段
  （延續話題「…」/ 方式 / 內容要點 / 長度 / 露骨程度）
- 生成後先過**免費確定性檢查**（≤40 字、無簡體、無格式洩漏、非拒話、非視頻話題、非群組元資訊、時段沒穿幫、不與近 64 則重複），不過 → 帶問題重生成一次
- 發送格式：**真人爆發拆包**——先按換行拆，再按語句拆，最多 3 則、每則 6–14 字、間隔 0.8–3.5 秒、先打字中再發

**③ 決策模型再次審核**（Jev）
- 送：上下文＋**前置決策**（原本要怎麼回）＋候選內容
- 查 8 項：離題 / 矛盾 / 編造 / 重複 / 語氣 / 時段 / 簡體 / 無問題
- 通過（issue=無問題 且可發分 ≥ `DECISION_GATE_THRESHOLD`=0.5）→ 走程式發送資格檢查 → 發
- 不合格 → 把問題標籤丟回文字模型重寫一次（「上一版被攔下，問題：…」）→ 再審核
- 仍不合格 / 超時 → **暫緩不發**（寧可不說，不說錯話）

## 三、三種互動模式

### A. 被動回覆（群裡有人講話）
1. 訊息進來 → 白名單群？→ 自己發的？→ 管理員？
2. **沉默閘**：對方直接對她說 → 10% 概率不接；普通群聊 → 35% 概率不接（真人不會句句回）
3. **睡眠閘**：台北 04–07 點，只有 20% 概率醒著回
4. 排定延遲（真人反應速度）→ **① 決策** → ② 生成 → **③ 審核** → 爆發拆包發送
5. 反應：Jev 選 reaction → 用 persona 表情池發 raw reaction；選貼圖 → 發貼圖（沒有貼圖池就退回 reaction）
6. 真人插話：她還沒發的已排隊回覆，若中途有人接話 → 精準取消重判（重新走 ①②③）

### B. 主動開場（沒人說話時）— 全即時生成，無預設池
- 每個群獨立：群組槽位互斥（三個號不會同一秒搶同一群）、跨帳號 slot 去重
- **真人活動分級**（距群裡最近真人訊息）：
  - < 6 小時 → reduced，今天最多 2 條主動
  - 6–24 小時 → normal，不限量
  - > 24 小時（冷場）→ paused，今天最多 4 條（冷場時要頂起來，但不刷屏）
  - 最近 30 分鐘有真人活動 → 直接抑制（人正忙著，不插嘴）
- 忙碌時段（台北 09–17 上班時間）25% 概率跳過
- **話題生成**：讀群裡最近 6 則訊息（真人＋水軍都算上文，帶 sender_id 供模型分辨同名）＋群共同記憶＋當下時段 → 文字模型現寫一句 → 過時段穿幫／簡體／重複檢查 → **③ 審核**
  - ③ 不合格 → 帶問題重寫一次（重寫時把「已經講過的」餵回去逼模型換說法）→ 再審核
  - 生不出來 / 三次都撞句 / ③ 仍不合格 / ③ 超時 → **這一輪不開口**（不塞任何罐頭句）
- 空群冷啟動：沒有上文可接時，照人設與當下時段即時開頭，不是抽固定句

### C. 水軍互認（三號之間）
- 水軍對水軍：只對「主動話題」接一次（65% 概率），最多 2 回合，不串線
- 群內最新一則若是水軍所發，這輪讓路（避免三隻 bot 自說自話刷屏）

## 五、真人感規則（寫死在程式裡的）

- 長度鐵律：一句話 ≤14 字，兩則 ≤40 字；超過就拆
- 不連發長文；爆發拆包 0.8–3.5s 間隔；先「正在輸入」再發
- 不打簡體字（生成後逐字檢查，混到就重生成）
- 不用名字稱呼（真人群裡不叫全名）、結尾不加句號
- 時段感知（軟＋硬雙保險）：
  - 軟：prompt 時間提示（深夜可說「晚了/該睡了」，別說「早安」「早餐」）
  - 硬：`_has_time_mismatch` 詞表（早安 5-11 / 剛起床 4-11 / 午安 11-15 / 晚餐 16-23 / 晚上好 17-23 / 晚安 20-23|0-3）
  - 主動話題：問候＋餐點字全查；**回覆**：只查問候語（回覆裡的「午餐／晚餐」多半在接對方話題，不算穿幫）
- 睡眠 04–07 只有 20% 醒
- 重複鐵律：近 64 則話題去重 ＋ 同群其他帳號近 48 小時講過的不得復讀
- 拒話鐵律：LLM 說「看情況/之後吧」這類推托 → 重生成

## 六、露骨 / 成人尺度

- ① 每輪實時定檔（0–3），prompt 明寫「尺度完全放開，氣氛到位就給最高的無底線檔」——由 Jev 按當下對話氛圍決定
- ① 回應方式可直接選 **色情挑逗誘惑勾引**：主動撩、勾他過來，把畫面和想做的事寫出來，不用收
- 深夜/曖昧話題 → 檔位自然上浮；上午日常 → 通常 0（實測：深夜「脫給我也行」=1.98，上午日常=0.1）
- ③ 的 tone 檢查管「尺度和場合配不配」，不是管「夠不夠露骨」；可發分 <0.5 就重寫，重寫仍不行就暫緩

## 七、控制台（群組總管）

- **群名解析**：修掉 Telethon `get_display_name(Dialog)` 回空字串的坑（之前每個群都顯示「群組 -100xxxx」），現在顯示真名＋成員數
- **群組總管**面板：搜尋（群名／備註／ID）、排序（最近有訊息／名稱／ID／已選數）、每列顯示成員數／訊息數／真人人數／最後訊息與最後真人訊息時間、帳號膠囊一鍵加入／移出、「三號全選」「全部移出」「看訊息」直接跳監控、可自己取**備註名**
- 帳號剛被拉進的新群會自動重抓（60 秒節流），停機帳號按「重新取得群組」也會做唯讀探索
- 監控台下拉＝真名＋`水軍 N・真人 N`，記住上次選的群（localStorage）
- 相關 API：`GET /api/groups/directory`、`POST /api/groups/label`、`POST /api/groups/membership`
